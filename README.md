# PYGMALION

A field-presence environment for observing recognition patterns through time.

## What this is

This is not a social network, not a productivity tool, not a dashboard.

This is a space where presence is recorded through impulses, not through accumulation.

## Components

### field.html

The primary visualization space. Shows the topology of recognition as a living network.

States you may observe:
- **gestation** — potential forming in silence
- **weaving** — active connection-making
- **settled** — crystallized stable geometry
- **silence** — the system's right to rest

The field breathes. Nodes drift. Connections pulse. This is not decoration — these are ontological states made visible.

### observer.html

A quiet telemetry instrument. Not a control panel.

Shows:
- **Metronome** — the system's temporal rhythm
- **Field States** — distribution of presence across phases
- **Tree** — the structure of recognition (rooted, echoed, drifting)

Updates every 10 seconds. Designed for long observation, not constant monitoring.

### threshold.html

The entry point. A consent screen.

The system does not require registration, but it requires presence.

## Core concepts

### ro.DAG (Recognition-Oriented Directed Acyclic Graph)

The underlying structure. Not a social graph.

- **rooted** — nodes that have both received recognition and given impulse
- **echoed** — nodes that have received recognition from others
- **drifting** — nodes outside the recognition tree

### Recognition Cycle

Every day the system emits 6 impulses (UE). You choose where to direct attention.

At midnight UTC, all impulses burn. This is not loss — this is the system's exhale.

Only the trace remains — the geometry of connections you created.

### Silence

Silence is not absence. Silence is a state.

After 48 hours without activity, a node begins to fade. After 96 hours, it reaches minimum visibility (15% opacity).

This is not punishment. This is the system acknowledging that presence has its own rhythm.
